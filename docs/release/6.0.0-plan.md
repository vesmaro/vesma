# 6.0.0 release branch — contract and breaking-change backlog

## Purpose

6.0.0 is the major for BREAKING/DESTRUCTIVE contract changes that cannot enter a minor per SemVer (owner ruling 2026-10-03). The 5.0.0 rebrand deliberately kept a compatibility layer; 6.0.0 removes/replaces it. Features and fixes keep landing on main and ship as 5.3+ minors — they ride into 6.0.0 via merges from main.

## Fill rules

1. Breaking deltas land directly on this branch.
2. Non-breaking work lands on main and is merged into this branch regularly (`git merge main` — never rebase the release branch).
3. No force-push. VERSION stays 5.2.0 until the release cut; no tag until cut.
4. Every breaking change updates this backlog file (checkbox) + CHANGELOG ([Unreleased] → 6.0.0 section when cut).
5. Cross-repo contracts (proto, binary names, ecosystem domains) ship in a coordinated window with vesma-mesh / vesma-eyes / vesma-agent releases.
