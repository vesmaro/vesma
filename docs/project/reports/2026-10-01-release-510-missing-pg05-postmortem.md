## 2. Пять процессных уроков (mnemos `1e9410bc`)

1. **`git branch --show-current` — перед merge**, и результат читать, а не
   игнорировать (после факта он показывал main; прочитан как норма).
2. **Снос ветки — только по merged-статусу PR** (правило уже было в hygiene
   policy — нарушено).

   релизной секции, обязан существовать в тег-дереве.
4. **Version-bump — часть релизного коммита до тега** (прокол №2).
5. **Спасли reflog и «не верь отчёту без диффа»** — двойной урок с
   PG-0.5-записью CHANGELOG.
